# Docs MCP Onboarding

A short onboarding log with four questions you can send to the Pharos Developer Docs MCP live. It uses the same fixed questions as the recorded run, so the answers can change when the docs change.

## Run locally

From this folder, run `npm install` and then `npx vercel dev`. Open the local URL Vercel prints.

The run buttons call `askQuestion` through the official Docs MCP endpoint. They do not connect a wallet or send transactions.
